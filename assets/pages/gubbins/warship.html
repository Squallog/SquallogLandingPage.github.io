Warship

THE TURRETS

Main Weapons

There are four primary turrets, each with three servos - 2 for gun elevation and 1 for turret traverse. These turrets are each controlled by an Arduino Uno which communicates with a Raspberry Pi using an I2C protocol. The Arduino Uno has a JSON file containing the name and positioning of the turret, these parameters are broadcast through I2C, facilitating "plug and play" functionality between the turrets and central control unit.

Turret Module

The turret module is an Arduino Uno running a Circuit Python script which transmits turret parameters to the central control module while receiving tareting commands and aiming the turrets accordingly. This module is responsible for controlling traverse (axial) and elevation. Traverse movement is controled using a 3 volt DC motor, a potentiometer reading is used to determine turret position. Two microswitches are placed at the extreme limits of turret rotation, on boot the turret is rotated left and then right until it triggers the respective microswitch. Potentiometer values are taken at each of the potentiometer triggers, these values are used to calibrate the relationship between potentiometer value and turret position.

Control Module

A Raspberry Pi acts as a hub, connecting to all of the turrets (primary, secondary, and otherwise) through I2C cables. Commands are received from a web server hosted remotely, with a SIM card facilitating communication. The module receives data telling it the position of a target relative to the center of the boat. Traverse instructions are calculated using the position of each turret (retreived from JSON data inside the turret modules) relative to the center of the boat.

Secondary Turrets

There are 6 secondary turrets, each with 2 servos - 1 for elevation and 1 for traverse.

Air Defence Turrets

There are 8 air defence turrets, these turrets do not have sufficient space inside for any servos or electronics. Elevation and traverse control is acheived using a pair of bicycle brake cables. An F 696Z flange bearing acts as the turret ring, a 6mm diameter basket protrudes through the bearing, with a small connecting horn extending from below such that a brake cable can traverse the turret. A hole of diameter 1.5mm allows a second cable to pass through, with a 5mm socket at its opening to connect the cable housing. Inside the anti aircraft turret, a compression spring keeps the cable under tension and ensures that the turret will elevate when the cable is relaxed.

THE SUPERSTRUCTURE

The superstructure is built around a wooden framework, assembled from lasercut plywood peices, with vertical supports being cut from 6mm ply and horizontal members cut from 3mm. Once complete, plastic paneling will be fixed around the framework. The funnel and foremast are built using 3D printer parts, facilitating their more complex curved geometry.
